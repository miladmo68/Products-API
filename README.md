## ​ Features

| Feature | Description |
| --- | --- |
|  **Mock API** | Uses JSON Server to provide realistic REST endpoints for product data |
|  **Quick Setup** | Great for frontend prototyping without needing a full backend |
|  **Deploy-Ready** | Hosted on Vercel or GitHub Pages for immediate access |
|  **Customizable Data** | Modify the JSON dataset to simulate various scenarios |
|  **Linted & Formatted** | Ensures consistent code quality and readability |

## ​ Getting Started

```bash
# 1) Clone the repository
git clone https://github.com/miladmo68/Products-API.git
cd Products-API

# 2) Install dependencies
npm install

# 3) Start JSON Server
npm run serve

# 4) Deploy (automatic via GitHub Pages/Vercel)
